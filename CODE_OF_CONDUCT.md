# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), v2.1.

In short: be respectful and constructive; no harassment, discrimination, or personal attacks.
Assume good faith and focus on the work.

Report unacceptable behavior to the maintainer (`korkin25`) privately. Reports are handled
confidentially.

The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.
